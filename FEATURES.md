# Liquidity Edge v6.0.0 — macOS Feature Overview

Liquidity Edge is a native macOS 14+ trading journal built exclusively with Swift, SwiftUI, SwiftData, Swift Charts, and AppKit.

| Area | Capabilities |
| --- | --- |
| **Dashboard** | Unboxed KPI ribbon, flagship linear equity curve ($/R/%) with interactive glass crosshair HUD, process & discipline rail, drawdown, rolling win rate, timing heatmap, recent trades, customizable widget layout |
| **Accounts & Risk** | Multi-account management (Personal, Evaluation, Funded), independent currencies & balances, static and EOD trailing drawdown, daily loss limit, minimum trading days, consistency percentage, unverified/breach alerts |
| **Strategy Research Lab** | Multi-dimensional filtering, saved filter presets, Setup × Session and Setup × Instrument matrices, confirmation counts, A/B cohort comparisons, weekday/time analysis, trade drill-down, sample-size warnings |
| **Quant & Monte Carlo** | Deterministic seeded bootstrap and shuffle resampling (5th/50th/95th percentile bands), drawdown distribution, underwater recovery duration, rolling expectancy, profit concentration |
| **Daily Plan & Checklists** | Daily pre-market scenarios, liquidity targets, strategy focus, risk limits, reusable QT/MMXM/CRT checklist templates |
| **Trade Inspector & Fills** | Execution sequence timeline, supplemental fills ledger (scale-in/out, fees, point/tick specs, slippage cost), structured checklist responses, annotated screenshots |
| **Trades & Calendar** | Full-text search, 20 analysis dimensions, date filters, sorting, month calendar with daily PnL/R drill-down |
| **Models & Process** | QT, MMXM, PO3, SSMT, TSMO, CRT, HTF alignment, liquidity sweeps, plan compliance, custom broken rules, 7 execution scores, emotional journal |
| **Playbook & Reviews** | Setup CRUD, five rule sections, ideal example images, daily/weekly/monthly live snapshot reviews |
| **Data & Backups** | Multi-step CSV Import Mapping Wizard with duplicate detection, SwiftData V1 → V2 lightweight migration, automatic daily recovery snapshots, V2 & legacy V1 JSON backups, isolated demo workspace |
